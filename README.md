An academic Artificial Neural Network (ANN) project developed for predictive maintenance on the UCI AI4I 2020 dataset. This system integrates electromechanical feature engineering, an actual **Simulated Annealing (SA)** metaheuristic optimization algorithm for feature subset selection, an imbalanced **Multilayer Perceptron (MLP)**, and an interactive **Streamlit** diagnostic dashboard.

---

## 1. Project Overview & Physical Problem Statement

In industrial manufacturing, catastrophic milling machine breakdowns cause costly downtime and hazardous work conditions. The objective of this project is to predict impending machine failures from real-time operational sensor telemetry before physical breakdown occurs.

### Real AI4I 2020 Dataset Summary
- **Source**: UCI Machine Learning Repository / Matan et al.
- **Samples**: 10,000 continuous machine operational readings.
- **Target (`Machine failure`)**: Binary indicator (`0` = Normal, `1` = Failure).
- **Class Imbalance**: 9,661 Normal (96.61%) vs. 339 Failures (3.39%).

### Prevention of Data / Target Leakage
The raw AI4I dataset contains 5 specific failure mode labels:
- `TWF`: Tool Wear Failure (46 instances)
- `HDF`: Heat Dissipation Failure (115 instances)
- `PWF`: Power Failure (95 instances)
- `OSF`: Overstrain Failure (98 instances)
- `RNF`: Random Failure (19 instances)

> **Critical Academic Safeguard**: In a real operational setup, the control system cannot know in advance *which* failure mode occurred. Passing these failure flags as input features constitutes **direct target leakage**. In this pipeline, these columns (along with arbitrary IDs `UDI` and `Product ID`) are **strictly excluded** from feature selection and neural network training. They are only utilized for post-hoc root-cause diagnostics.

## 2. Electromechanical Feature Engineering

To provide domain-informed representations for the neural network, three physical features are computed:

1. **Temperature Differential ($\Delta T$)**:
   $$\Delta T = T_{\text{process}} - T_{\text{air}}$$
   *Physical Meaning*: Reflects thermodynamic heat accumulation in the milling chamber. High differentials indicate inadequate cooling lubrication.

2. **Electromechanical Rotational Power ($P_{\text{mech}}$)**:
   $$P_{\text{mech}} = \tau \times \omega = \tau \times \left( \text{rpm} \times \frac{2\pi}{60} \right)$$
   *Physical Meaning*: The mechanical shaft power delivered to the spindle in Watts ($W$). Sudden drops or surges indicate drive stalls or power supply faults.

3. **Cumulative Overstrain Stress**:
   $$\text{Overstrain} = \text{ToolWear [min]} \times \tau \text{ [Nm]}$$
   *Physical Meaning*: Measures structural fatigue resulting from operating a worn cutter under excessive cutting torque.

Total Candidate Features ($D = 11$):
- Base Sensors: `Air temperature [K]`, `Process temperature [K]`, `Rotational speed [rpm]`, `Torque [Nm]`, `Tool wear [min]`
- Engineered: `Temp_Diff [K]`, `Power [W]`, `Overstrain`
- Categorical Variants: `Type_H`, `Type_L`, `Type_M` (One-hot encoded)

## 3. Simulated Annealing (SA) Feature Selection

Simulated Annealing is a probabilistic metaheuristic inspired by the metallurgical annealing of metals, capable of escaping local optima when navigating the $2^{11} = 2,048$ combinatorial state space.

### Mathematical Formulation

1. **State Representation**:
   $$\mathbf{s} = [s_1, s_2, \dots, s_D] \in \{0, 1\}^D \quad \text{where} \quad \sum_{i=1}^D s_i \ge 1$$
   $s_i = 1$ indicates feature $i$ is included; $0$ denotes omission.

2. **Parsimonious Energy Function ($E$)**:
   $$E(\mathbf{s}) = - \left( \text{F1}_{\text{val}}(\mathbf{s}) - \lambda \cdot \frac{\sum_{i=1}^D s_i}{D} \right)$$
   - Maximizing validation $\text{F1}$ is equivalent to minimizing energy $E(\mathbf{s})$.
   - $\lambda$ (default $0.02$) acts as a parsimony penalty discouraging redundant sensor inputs.

3. **Neighbor Perturbation Operator**:
   A candidate neighbor $\mathbf{s}'$ is generated by randomly flipping 1 or 2 bits in the mask, with an assertion preventing the null state $\mathbf{0}$.

4. **Metropolis Acceptance Probability**:
   $$\Delta E = E(\mathbf{s}') - E(\mathbf{s})$$
   $$P(\text{accept}) = \begin{cases} 1.0, & \text{if } \Delta E \le 0 \\ \exp\left(-\frac{\Delta E}{T}\right), & \text{if } \Delta E > 0 \end{cases}$$
   Early iterations ($T$ large) allow exploratory uphill moves ($\Delta E > 0$) to escape local traps; as $T \to 0$, the algorithm transitions to strict greedy descent.

5. **Geometric Cooling Schedule**:
   $$T_{k+1} = \alpha \cdot T_k \quad (\alpha = 0.92, \; T_0 = 1.0)$$

## 4. Artificial Neural Network (MLP) Architecture

- **Model**: `sklearn.neural_network.MLPClassifier`
- **Topology**: Input ($D_{\text{selected}}$) $\to$ Dense Layer 1 (64 neurons, ReLU) $\to$ Dense Layer 2 (32 neurons, ReLU) $\to$ Output (1 sigmoid probability).
- **Imbalance Handling**: Balanced sample weighting applied during gradient descent:
  $$w_c = \frac{N}{2 \times N_c}$$
- **Threshold Optimization**: Decision threshold $t^*$ is calibrated on validation data by maximizing the F1-score over $t \in [0.10, 0.90]$.

## 6. Quickstart Guide

### 1. Installation
Clone or navigate to the workspace, then install requirements:
```bash
pip install -r requirements.txt
```

### 2. Run Test Suite
Verify all unit tests pass:
```bash
python -m unittest tests/test_pipeline.py
```

### 3. Run Training & Simulated Annealing Pipeline
Execute the complete pipeline with customizable arguments:
```bash
python train_and_evaluate.py --n-iterations 60 --t0 1.0 --alpha 0.92 --penalty 0.02
```

### 4. Launch the Streamlit Dashboard
```bash
streamlit run app.py
```

## 7. Streamlit Dashboard Features

The web interface is organized into 4 interactive tabs:
1. **Dataset Explorer & Mechanics**: View real distributions, correlation heatmaps, class ratios, and physical sensor distributions.
2. **Simulated Annealing Visualizer**: Interactive Plotly trajectories of Temperature decay, Energy minimization, F1-score progression, and Feature Selection frequencies.
3. **Model Benchmark & Diagnostics**: Comparative performance table between Baseline (All Features) and SA-Optimized ANN, alongside interactive ROC curves, Precision-Recall curves, and Confusion Matrices.
4. **Live Machine Health Simulator**: Interactive control sliders for Spindle Speed, Torque, Temperatures, and Tool Wear with real-time failure probability gauge, risk level alerts, and sub-failure diagnostic reasoning.
